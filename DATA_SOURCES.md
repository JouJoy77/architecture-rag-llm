# Источники базы знаний

Источник — англоязычная [Rick and Morty Wiki](https://rickandmorty.fandom.com/).
Авторы исходных статей — участники этой вики (Rick and Morty Wiki contributors).

По [странице авторских прав вики](https://rickandmorty.fandom.com/wiki/Rick_and_Morty_Wiki:Copyrights),
тексты распространяются на условиях [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/),
если для отдельного материала не указано иное. Здесь используются только тексты статей;
изображения, видео, сценарии и реплики из таблиц с цитатами не скачиваются в базу.
Адаптированные документы в `knowledge_base/` и текстовый снимок в `data/source_snapshot.json`
также распространяются на условиях CC BY-SA 3.0. Это указание относится к данным, а не к коду проекта.

В `data/source_snapshot.json` для каждого документа сохранены название исходной статьи,
ссылка на неё и историю правок (для атрибуции участников), ID страницы, ID ревизии,
если он присутствовал в HTML, SHA-256 полученного HTML и время получения страницы.
Время создания самого снимка указано отдельно.
Перечень выбранных страниц находится в `data/kb_sources.json`.

Изменения относительно источников: выбраны содержательные абзацы, удалены HTML и служебные
блоки, упоминания производства сериала; имена, названия и обозначения заменены по `terms_map.json`.
Это учебная адаптация, а не каноническая энциклопедия исходной вселенной.

В индекс должны попадать **только `knowledge_base/*.md`**. Снимок исходных текстов,
словарь замен, этот документ и проектный отчёт в индекс не загружаются.
