# architecture-rag-llm

Решения по заданиям — в [Project_template.md](Project_template.md).

## База знаний

Источник — Rick and Morty Wiki. В `knowledge_base/` лежат 36 статей с вымышленными
названиями; один файл соответствует одной сущности. База на английском языке.
Источники и условия использования — в [DATA_SOURCES.md](DATA_SOURCES.md).

Подготовка данных (Python 3.11+):

```bash
python -m pip install -r requirements-data.txt
python prepare_knowledge_base.py --offline
python prepare_knowledge_base.py --check
python -m unittest discover -s tests -p 'test_prepare_knowledge_base.py' -v
```

`--offline` собирает базу из сохранённого снимка без сети. `--check` только
проверяет данные и их соответствие снимку, не меняя файлы.

Для скачивания текущих версий выбранных страниц через публичный MediaWiki API:

```bash
python prepare_knowledge_base.py
```

Ответы API кэшируются в `.cache/wiki/`. Для обновления конкретной статьи удаляется
её файл кэша; для полного обновления — каталог `.cache/wiki/`. Изменения вики могут
изменить результат. Точный повтор текущей версии делается через `--offline`.

`data/kb_sources.json` задаёт страницы и новые имена, `terms_map.json` — замены,
`data/source_snapshot.json` — очищенные исходные абзацы и сведения об источниках.
В RAG-индекс загружаются **только `.md` и `.txt` из `knowledge_base/`**.

## Векторный индекс

Модель — [intfloat/multilingual-e5-base](https://huggingface.co/intfloat/multilingual-e5-base),
768 измерений. Индекс — FAISS `IndexFlatIP`, векторы нормализованы для cosine similarity.
Версия модели закреплена в `vector_index/manifest.json`.

| Параметр | Значение |
| --- | --- |
| База | 36 документов из `knowledge_base/` |
| Чанки | 120 |
| Размер | 100–261 слово; один короткий документ сохранён целиком: 97 слов |
| Максимальный вход E5 | 409 токенов, включая префикс и заголовок |
| Генерация эмбеддингов | 41,652 с на CPU, 4 потока, batch size 8 |
| Сборка с загрузкой модели из кэша | 47,464 с; первое скачивание модели в замер не входит |

Установка и первая сборка (модель один раз скачивается в игнорируемую `.cache/models/`):

```bash
python -m pip install -r requirements-index.txt
python build_index.py
```

Повторная сборка без сети, поиск и проверка:

```bash
python build_index.py --offline
python search_index.py "Какую долю энергии Nezuko Delomi забирает из Lesser Realm?" --top-k 3
python evaluate_retrieval.py
python -m unittest discover -s tests -v
```

Поиск использует только локальный кэш модели. Сохраняются `vector_index/faiss.index`,
`chunks.jsonl` и `manifest.json`: тексты, ID, файл-источник, заголовок, разделы, строки,
символьные позиции и контрольные суммы. При изменении, добавлении или удалении
документов поиск требует пересборки индекса.

Для шести контрольных вопросов на русском и английском ожидаемый источник найден первым,
а нужные факты присутствуют в top-5. Полные запросы и найденные фрагменты:
[reports/retrieval_examples.md](reports/retrieval_examples.md) и JSON рядом.
Это небольшая проверка поиска, а не оценка качества ответов LLM. Score — cosine similarity,
не вероятность правильного ответа. Генерация ответов будет следующим этапом.

## RAG-бот

`rag_bot.py` связывает E5, FAISS и локальную Qwen3.5-9B Q5_K_M через llama.cpp.
Отдельных Python-зависимостей сверх `requirements-index.txt` нет.

1. Установить зависимости и один раз скачать GGUF:

   ```bash
   python -m pip install -r requirements-index.txt
   python local_model.py download
   ```

   Веса занимают 7,1 ГБ и сохраняются в игнорируемый `.cache/models/`. Репозиторий,
   ревизия, SHA-256 и параметры запуска закреплены в `data/llm_config.json`.

2. Установить [llama.cpp b12058](https://github.com/ggml-org/llama.cpp/releases/tag/b12058)
   для своей ОС. Для Linux и NVIDIA можно взять архивы `llama-b12058-bin-ubuntu-cuda-12.8-x64.tar.gz`
   и `cudart-llama-b12058-bin-ubuntu-cuda-12.8-x64.tar.gz`, распаковать оба в один каталог.
   CUDA-сборка требует совместимого драйвера NVIDIA. Затем запустить сервер в первом терминале:

   ```bash
   python local_model.py serve --server /path/to/llama-server
   ```

   По умолчанию слои отправляются на GPU. Для CPU передать `--gpu-layers 0`.
   Сервер слушает только `127.0.0.1:18080`: контекст 4096, один слот, thinking выключен.
   Vision-проектор не используется. Дождаться сообщения о готовности сервера.

3. Во втором терминале запустить REPL или задать один вопрос:

   ```bash
   python rag_bot.py
   python rag_bot.py "Какой киборг был создан из Avor Kel?"
   python rag_bot.py "Какой киборг был создан из Avor Kel?" --json
   ```

   Выход из REPL — `/exit` или Ctrl+D. Вопросы независимы: история диалога в промпт
   не переносится. Бот показывает краткие шаги проверки, цитаты, ответ и ссылки на
   файлы со строками и ID чанков. Если данных нет — «Я не знаю.».

Few-shot — два примера с реальным чанком `Taskling Cradle`: ответ о назначении
устройства и отказ на вопрос о его массе. Для нового вопроса разрешены только
текущие источники, а не контекст примеров. CoT реализован как короткое объяснение
по подтверждающим фактам и итоговый ответ; внутренний монолог не выводится.

Размер промпта проверяется токенизатором Qwen через llama.cpp с учётом шаблона,
инструкций, примеров и резерва ответа. При нехватке места удаляются последние
результаты поиска. Неполный ответ, неизвестная ссылка или отсутствующая в источнике
цитата считаются ошибкой, а не отсутствием знаний. Проверка цитат не доказывает,
что все выводы модели верны: смысл ответа также нужно проверять.

Повторить примеры с работающим сервером:

```bash
python evaluate_rag.py
python -m unittest discover -s tests -v
```

В `data/rag_questions.json` — пять вопросов с ответами и два без ответа. Скрипт сохраняет
реальный вывод модели, найденные чанки, параметры и замеры в `reports/rag_dialogues.json`,
читаемые диалоги — в `reports/rag_dialogues.md`. Проверяются статус, источник и контрольные
слова; это небольшие smoke-тесты. Время каждого примера включает поиск, подготовку
промпта и генерацию, без первоначальной загрузки моделей и индекса.
Все обращения к LLM идут на локальный адрес;
облачные API и ключи не нужны. После загрузки весов RAG работает без сети.

Сохранённый прогон: **7/7**, пять ответов с цитатами и два «Я не знаю»;
[диалоги](reports/rag_dialogues.md). Проверка выполнена на CPU в виртуальной машине
с 8 vCPU и 16 ГБ RAM, без доступной GPU. Скорость на 4070 Ti пока не измерялась.

Справка по запуску: [карточка Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B),
[API llama.cpp](https://github.com/ggml-org/llama.cpp/blob/b12058/tools/server/README.md).
